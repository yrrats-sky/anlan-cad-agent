# 安岚CAD助手

AutoCAD 内置的 AI 助手面板(anlanai.cc 出品)。

**安装**:下载 [anlan-cad-setup-v0.4.5.exe](https://github.com/yrrats-sky/anlan-cad-agent/releases/download/v0.4.5/anlan-cad-setup-v0.4.5.exe) → 双击安装(全程免管理员、无 UAC)→ 重启 AutoCAD,打开任意图纸,右侧自动出现「安岚助手」面板。

密钥在 [anlanai.cc 控制台](https://anlanai.cc/console/token)创建(sk- 开头),装好后点面板 ⚙ 填入。当前支持 AutoCAD 2021-2027(64 位;2023/2024/2025/2026/2027 全量验证,2021/2022 兼容模式);大陆下载慢可用[站内镜像](https://anlanai.cc/downloads/)。
